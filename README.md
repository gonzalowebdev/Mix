# Mix

Reproductor Android de imágenes y videos del dispositivo, con filtros, orden, búsqueda y listas de reproducción.

- Kotlin + Jetpack Compose
- MediaStore (lectura de la galería), Media3/ExoPlayer (video), Coil (miniaturas, GIF/WebP), Room (listas)
- El APK se compila solo con GitHub Actions: pestaña **Actions** (artefacto) o sección **Releases**.
